スマホ歩数 自動連携ガイド

Google Fit API は現在 Health Connect へ統合されたため、スマホの自動化機能から以下の送信先URLへ歩数をPOST送信することで自動記録できます。

送信先 Webhook URL（POST）
送信 JSON 形式（例）:
{"date": "2026-11-19", "steps": 8450}
  • iPhone: 「ショートカット」アプリのオートメーション（毎日23:50）で「ヘルスケアサンプルを検索（歩数）」→「URLの内容を取得（POST / JSON）」を設定。
  • Android: 「ヘルスコネクト」の歩数を MacroDroid / Tasker 等で取得し、上記URLへ HTTP POST 送信。
